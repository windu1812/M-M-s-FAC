# M-M-s-FAC - CreditLens

CreditLens turns public SEC EDGAR filings into a 5-year credit screen (leverage, coverage, liquidity, cash flow) with red flags and an Excel export, for corporate bankers and credit analysts.

- The application lives in `app/`. Install, run and test instructions: see `app/README.md`.
- Product documents: `docs/`. AI disclosure: `AI-USAGE.md`.
